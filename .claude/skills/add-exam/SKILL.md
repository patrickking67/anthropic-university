# Add a new exam track

Scaffold a new track so it flows through the build pipeline and shows up in the web app automatically.

## Steps

1. Create `content/<exam-id>/questions.json` with the top-level shape:

```jsonc
{
  "examId": "<exam-id>",                 // MUST equal the folder name
  "title": "<Full Title>", "shortTitle": "<short>", "track": "<Track>", "level": "<Level>",
  "unofficial": true,
  "meta": { "questionCount": 100, "passScaled": 720, "scaleMin": 100, "scaleMax": 1000, "timeMinutes": 120 },
  "domains": [ { "id": "<slug>", "name": "<Domain Name>", "weight": 0.2 } ],
  "questions": []
}
```

2. Create `content/<exam-id>/flashcards.json`: `{ "examId": "<exam-id>", "title": "<Full Title>", "cards": [] }`.
3. Create `content/<exam-id>/study-guide.md` organized by the domains you declared.
4. Add `<exam-id>` to the `EXAM_ORDER` array in `scripts/build.mjs` (controls display order).
5. Author questions with the `author-questions` skill, then run `node scripts/build.mjs`.

The web app reads `docs/data/index.js` + `docs/data/<exam-id>.js`, both generated by the build — no
front-end changes are needed to add a track.
