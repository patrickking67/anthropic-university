# Learning paths (role → lanes → certification)

Use this to recommend where to start. The order within each path is the suggested sequence. Lanes
are `/anthropic-university:learn <lane-id>`; exams are `/anthropic-university:study-plan <exam-id>`.

| Role / goal | Path | Certification |
| --- | --- | --- |
| New to Claude, any role | claude-essentials → claude-for-work | associate-foundations |
| Business power user / team lead | claude-essentials → claude-for-work → prompt-engineering | associate-foundations |
| Software developer | claude-api-fundamentals → prompt-engineering → claude-code → mcp-and-integrations → building-agents | developer-foundations |
| Solutions / platform architect | claude-api-fundamentals → claude-code → mcp-and-integrations → building-agents | architect-foundations → architect-professional |
| IT admin / security | claude-essentials → enterprise-administration → desktop-deployment | associate-foundations |
| Endpoint / MDM engineer | desktop-deployment → enterprise-administration | — |
| Partner: sales / account lead | partner-foundation-models → partner-enterprise-solutioning → industry-solutions | associate-foundations |
| Partner: solutions consultant | partner-foundation-models → partner-enterprise-solutioning → partner-delivery-adoption → claude-api-fundamentals | architect-professional |
| Partner: delivery / change lead | partner-delivery-adoption → enterprise-administration → claude-for-work | associate-foundations |
| Legal / professional services | claude-essentials → claude-for-work → industry-solutions | associate-foundations |

Partner practice: pair each partner lane with `/anthropic-university:client-roleplay`.
